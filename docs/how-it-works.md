# 三步上手：扫盘 → 封面墙 → 点播

本地视频库把硬盘文件夹变成可刷的私人影院。下面三张图讲清核心路径。

## 1. 扫盘

选盘符后点 **扫描所选盘**。新盘会自动加入统一片库，多块盘可以一起挂着。

![扫盘](images/01-scan.jpg)

## 2. 封面墙

扫描完成后左侧按 **频道 / 盘** 浏览，中间是封面墙。可按类型、格式筛选，也可用拼音 / `ext:mkv` 搜索。

![封面墙](images/02-cover-wall.jpg)

## 3. 点播

点封面即可播放：浏览器内播；难播格式可用系统播放器。m3u8 / TS 可转 MP4，浏览器无声可修声音。

![点播](images/03-play.jpg)
