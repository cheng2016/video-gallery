# 示例片库目录（可扫）

把你自己的短视频 / 样片按下面结构丢进来，然后在软件里 **扫描这个文件夹**（或把整个 `demo-library` 当根目录），即可看到频道与封面墙效果。

```
demo-library/
├─ 电影/
│  ├─ 动作/     ← 放 .mp4 / .mkv
│  └─ 科幻/
├─ 电视剧/
│  └─ 示例剧/
│     └─ Season 01/   ← 文件名可用 S01E01、第1集
└─ 动漫/
```

## 建议

- 每个分类放 1～3 个短片即可（不必整部电影）
- 文件名可带演员：`片名.张三.李四.1080P.mkv`（会尝试抠演员用于搜索）
- 搜拼音：`xingji` / 首字母 `xj`；语法：`ext:mkv` `genre:科幻` `actor:张三`

> 仓库不内置真实视频（体积与版权）。你放入样片后即可本地演示；对外分享可用录屏做成 GIF，放到 `docs/images/demo.gif`。
